# 映像を読む7つの観点

すべてを毎回埋める必要はない。印象を左右する要素を選び、観察と解釈を分ける。

| 観点 | 観察すること | 理由を考える問い |
|---|---|---|
| 構図 | 主役の位置、余白、視線、寄りと引き | 最初に何に気づいてほしいか？ |
| 光 | 明るい面、影の境界、光の方向、明暗差 | 日差し・柔らかさ・緊張感のどれを強めるか？ |
| 色と質感 | 支配色、差し色、肌、布、ガラス、粒状感 | 商品のどの印象と結びつくか？ |
| 人物と動作 | 表情、視線、姿勢、重心、衣服の揺れ | 観客が共感する身体感覚は何か？ |
| カメラ | 固定・追従・接近、高さ、被写体との距離 | 観客を傍観者にするか、その場にいる人にするか？ |
| 編集 | カット順、見せる時間、動作のつながり | 注意・感情・商品の理解がどう変化するか？ |
| 音 | 聞き取れた環境音、音楽、声、無音 | 何を予感させ、どこを印象づけるか？ |

## 記述例

- 観察：画面左側の頬に濃い影があり、右側の肌は明るい。
- 仮説：顔の立体感と強い日差しを感じさせる狙いがありそう。確からしさは中。時間帯自体は画から確定できない。
- 提案：強い光を伝えたいなら、画面右上からの光と頬の陰影を指定する。柔らかさが目的なら明暗差を弱める。

## よくある飛躍

- 背景がぼけている → 「85mm・F1.4」と断定しない。距離・センサー・合成でも変わる。
- 人物が別の位置にいる2枚 → 「走っている」と断定しない。別テイクかもしれない。
- 滑らかな映像 → 「高fpsで撮影」と断定しない。
- 葉が揺れている → 鳥の声まで聞いたことにしない。
- 表情が乏しい → 指定不足と即断せず、演技の狙い・生成制約・採用フレームも考える。
- 要約文に書かれた描写 → 実映像で確認できた事実と扱わない。
